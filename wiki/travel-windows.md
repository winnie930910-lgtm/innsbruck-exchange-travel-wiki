# 🗓️ 可旅遊時段總表

> 以 2027.02.15 ~ 2027.07.31 交換期間為範圍，對應茵斯布魯克大學行事曆，整理出最適合出遊的時段。

---

## 交換期間快速概覽

```
2月中  3月       4月            5月                 6月          7月
 ├──▶│課  課  課│ 復活節假期 │課 課 假課 假 課 假│暑  │交換結束
     ↑          ↑           ↑                   ↑
   課程開始   復活節假         單日國定假         暑假/交換尾聲
   03.01      03.22-04.03   多個四至週四拼連假  06.28
```

---

## 各旅遊時段分析

### 🟡 2027.02.15 ~ 2027.02.28｜抵達適應期

| 項目 | 說明 |
|------|------|
| 學期狀態 | 冬季學期學期中休假（Semester break：02.03 ~ 02.27） |
| 旅遊條件 | 無課，自由度高 |
| 季節 | 冬末，阿爾卑斯積雪，日照短，氣溫低 |
| 建議 | 適合茵斯布魯克周邊短途（慕尼黑、薩爾茨堡）或滑雪體驗。長途旅行建議等春季。 |

---

### 🟢 2027.03.01 ~ 2027.03.21｜上課期間（開學前三週）

| 項目 | 說明 |
|------|------|
| 學期狀態 | 夏季學期正式開始（03.01），開始上課 |
| 旅遊條件 | 僅週末可出遊 |
| 季節 | 冬末 → 初春，天氣轉暖中 |
| 建議 | 週末快閃：慕尼黑（2h）、薩爾茨堡（2h）、維也納（4.5h）等鐵路可達城市 |

---

### 🔴 2027.03.22 ~ 2027.04.03｜**復活節假期（最佳長假！）**

| 項目 | 說明 |
|------|------|
| 學期狀態 | **無課，約 13 天長假** |
| 旅遊條件 | ✅ 最佳長途旅遊時段之一 |
| 季節 | 春季，天氣宜人 |
| 注意 | 復活節是歐洲大型節日，觀光地人多，住宿需提早訂；部分景點週日/週一休息 |
| 建議目的地 | 義大利（威尼斯/佛羅倫斯/羅馬）、克羅埃西亞、捷克布拉格、希臘（南歐天氣已回暖） |

---

### 🟢 2027.04.07 ~ 2027.04.30｜上課期間

| 項目 | 說明 |
|------|------|
| 學期狀態 | 復課 |
| 旅遊條件 | 僅週末 |
| 季節 | 春季，天氣佳 |
| 建議 | 週末快閃義大利北部（維羅納、威尼斯）或德國南部 |

---

### 🟡 2027.05｜多個短假期（可拼連假）

| 日期 | 假日名稱 | 星期 | 連假潛力 |
|------|----------|------|----------|
| 05.01 | 勞動節 | 週六 | 低（本週六） |
| 05.06 | 耶穌升天節 | **週四** | ✅ 高：週四假可搭週五請假拼 4 天連假 |
| 05.17 | 聖靈降臨節翌日 | **週一** | ✅ 高：週六-週日-週一長週末 |
| 05.27 | 基督聖體節 | **週四** | ✅ 高：同升天節，可拼 4 天 |

> 💡 **技巧**：05.06（週四）和 05.27（週四）各可搭配請一天 05.07（週五）或 05.28（週五），形成 4 天連假。

---

### 🌟 2027.06.01 ~ 2027.06.27｜學期尾聲（最佳旅遊季！）

| 項目 | 說明 |
|------|------|
| 學期狀態 | 有課至 06.26 |
| 旅遊條件 | 週末可出遊 |
| 季節 | ⭐ **歐洲最佳旅遊季**：日照長（晚上 9 點天亮）、氣候宜人、尚未到暑假人潮高峰 |
| 建議 | 週末把握旅遊，氣候最好，性價比最高 |

---

### 🌟 2027.06.28 ~ 2027.07.31｜**交換尾聲自由期（⚠️ 留意期末考時程）**

| 項目 | 說明 |
|------|------|
| 學期狀態 | 暑假開始（06.28起），無常態授課。**但留意期末考試期（約至 07.23 左右）** |
| 旅遊條件 | 需個人確認無考試後，方為自由期 |
| 季節 | 夏季，日照最長，但南歐（西班牙、希臘）可能高溫 35°C+ |
| 建議 | 7月下旬考試結束後安排：北歐（挪威、冰島）、東歐（波蘭、波羅的海）避暑；或在中歐、奧地利境內輕鬆收尾 |
| 注意 | ⚠️ **授課結束 ≠ 考試結束**！7月初至中旬仍可能安排期末筆試或報告繳交（通常到 7/23 前後）。7月是歐洲旅遊旺季，住宿和交通需提早訂，但務必確認考程無衝突。 |
